## Features

- **Your sources:** M3U, M3U8 and XSPF playlists and Xtream Codes logins, with XMLTV (EPG) guide data.
- **Live TV:** categories, channel numbers, now and next on every channel, favourites and search.
- **TV guide:** now and next for free; the full timeline grid with Pro.
- **Movies and series:** posters, details, seasons and continue watching.
- **Catch-up and start over** where your provider records programmes.
- **Sport:** today's games matched to the channels in your own list.
- **Encrypted sync:** one code links your PC with your phone, tablet and TV (Pro). End-to-end encrypted, no account.
- **Keeps itself up to date** in the background.

## Install

1. [Download `iptvolt-Setup.exe`](https://github.com/schantastic/iptvolt-desktop/releases/latest/download/iptvolt-Setup.exe) and run it. It installs in one click, no admin rights needed.
2. Windows may show **"Windows protected your PC"** for new apps: choose **More info**, then **Run anyway**.
3. Add your M3U link or Xtream login, or scan the sync code with the iptvolt phone app (Pro).

Requires Windows 10 or 11, 64-bit.
