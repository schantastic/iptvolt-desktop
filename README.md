# iptvolt for Windows

Download: https://github.com/schantastic/iptvolt-desktop/releases/latest/download/iptvolt-Setup.exe

iptvolt is a player for your own IPTV sources (Xtream, M3U, XSPF). It ships no channels or content.
The app updates itself. On first start Windows may show "Unknown publisher": More info → Run anyway.

Made by [Schantastic](https://iptvolt.com) · contact@schantastic.com

This repository only hosts the release files (built locally, uploaded by the iptvolt release script).
